# Majulah Hunt All-Class Dashboard

Upload these files to the same GitHub Pages repository:

- `all-classes.html`
- `all-classes.js`

Also copy the contents of `styles-addition.css` to the bottom of your existing `styles.css`.

The dashboard uses the existing:

- `config.js`
- Google Apps Script `/exec` URL
- `status` endpoint
- class data from `2-1` to `2-8`

Open:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/all-classes.html
```

It refreshes automatically using the interval set in `config.js`.

Each class card shows:

- completed stations
- required stations
- station points
- pledge point
- total points
- challenge completion status
- link to the class-specific display
